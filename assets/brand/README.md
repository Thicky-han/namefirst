# NameFirst brand assets

The approved mark combines the N/F initials with an upward mint arrow,
representing name matching and official-site priority. The public preview
was approved on 2026-10-14 with the taller F variant.

- `namefirst-master.png`: accepted master pixels, stripped of ancillary metadata.
- `namefirst-512.png`: GitHub README/project artwork export.
- `extension/src/icons/namefirst/icon-{16,32,48,128}.png`: browser PNG exports.

These exports preserve the accepted design, colors, proportions and opaque
white framing. No additional artistic alteration was made during export.
The master was created with the built-in image-generation tool and resized
for distribution; it does not copy the upstream uBlacklist prohibition mark.
